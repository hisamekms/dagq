# The layer and context violations scripts/check-layer-deps.sh allows today.
# The rules and what counts: docs/design/architecture.md, sections
# "レイヤーの規則", "コンテキストの規則" and "検査の範囲" (the details of what
# counts: the script's header). This header
# holds the format.
#
# One item per line, `rule | path | reference | task | reason`; lines that
# start with `#` and blank lines are not read. rule is one of L2, C3 and C8
# (what clippy.toml holds of L2, L4, L5 and L7 is not here; L1, L3, L6, L8
# and L9 are allowed in the table of the Rust test,
# src/context_boundaries/ownership.rs); path is a file from `src/`;
# reference is the reference as the script prints it; task is one task ID
# or several separated by `,`; reason is not empty. The same reference in
# the same file is one item. A reference
# with no item, an item whose reference is gone (the task that fixes a
# violation removes its item in the same change), a malformed line and a
# duplicate item all fail the check.
#
# rule | path | reference | task | reason
