# Nothing in this tree reads this list any more: C5, C8 and the records of
# the ports are the Rust test src/context_boundaries/modules.rs with the
# table src/context_boundaries/ownership.rs, which holds the rows below.
# The list stays, unchanged, only because the program review of a run runs
# the landing branch's scripts/check-context-boundaries.sh, and an older
# one reads it; it goes with the script (ADR-t2397-1 decision 4, stage 3).
# Do not change it to follow the code.
#
# The ownership of the runtime's contexts that the module paths do not tell,
# read by scripts/check-context-boundaries.sh for the rule C5 (its meaning:
# docs/design/architecture.md, section "コンテキストの規則"; what counts:
# the script's header). The tables, the store modules of src/infrastructure/
# and the transactions are in src/context_boundaries/ownership.rs. This
# header holds the format.
#
# One item per line, `kind | field | ...`, fields trimmed; lines that start
# with `#` and blank lines are not read. A context is one of planning (計画管理),
# execution (実行と着地), observation (観測と分析), host (host運用) and shared
# (共有の部品). `to` (whom a port, a method or an item is public to) is `all`,
# one context or several separated by `,`, or `-` for none. The last field of
# every kind is a note (a reason where the kind says so) and may be empty
# unless it is a reason.
#
#   module | <path> | <context> | <note>
#       The context of a module of src/application/ that its path does not
#       tell (a file, or a directory ending in `/`). Not for the paths the
#       script derives (below).
#   port | <Trait> | <public|internal|partial> | <to> | <note>
#       Whom a port of src/application/ports/<context>.rs is public to; its
#       owner is the file's context. Every pub trait of those files (but
#       mod.rs) must have one. `internal` takes `to` -, `partial` takes
#       `to` - and its methods in `method` items.
#   outer-port | <path> | <Trait> | <owner> | <public|internal|partial> | <to> | <note>
#       A port defined outside src/application/ports/, in the file <path>.
#       owner is `-` where the path tells it (queue_reads/<context>.rs).
#   not-port | <path> | <Trait> | <reason>
#       A pub trait of src/application/ outside ports/ that is not a port.
#       Every pub trait of src/application/ outside ports/ must be an
#       outer-port or a not-port.
#   method | <Trait> | <method> | <to> | <note>
#       A method of a `partial` port public to `to`; its other methods are
#       internal. The method must be declared in the trait's body.
#   item | <path> | <name> | <owner> | <to> | <note>
#       A value or a function (not a trait) one context lends to others; the
#       name must be defined (struct, enum, union, fn, type, const, static,
#       mod, trait) in <path>; whom it is lent to is not checked.
#
# The script derives, and this list does not write: the owner of a trait of
# src/application/ports/<context>.rs, and the context of
# src/application/ports/<context>.rs, src/application/queue_reads/<context>.rs
# and src/compose/<context>.rs. The script reads the context of a store
# module of src/infrastructure/ from the Rust table's store rows.
