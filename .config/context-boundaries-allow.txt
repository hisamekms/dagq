# The C5 violations scripts/check-context-boundaries.sh allows today (the
# C1 ones are rows of src/context_boundaries/ownership.rs). The rule:
# docs/design/architecture.md, section "コンテキストの規則"; what counts:
# the script's header. This header holds the format.
#
# One item per line, `rule | path | reference | task | reason`; lines that
# start with `#` and blank lines are not read. rule is C5; path is a file
# from `src/`; reference is the port as the script prints it; task is one task ID
# or several separated by `,`, or `none` when no task fixes it yet (the
# reason then says it is unregistered); reason is not empty. The same
# reference in the same file is one item. A violation with no item, an item
# whose violation is gone (the task that fixes a violation removes its item
# in the same change), a malformed line and a duplicate item all fail the
# check.
#
