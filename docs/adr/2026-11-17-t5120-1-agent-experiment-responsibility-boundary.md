# ADR-t5120-1: Agent比較実験の責務境界

## Context

人の設計依頼は、役割に使うagentを変えて比較し、評価観点が変わっても観測事実を再分析できる基盤を求める。
速さ・費用・品質を単一の指標に畳むと、その時点の価値判断がruntimeに入り、modelや分析目的が変わるたびに基盤を直すことになる。
実験の群の重みと、評価指標の重みも異なる責務である。

ADR-t3957-1決定5とADR-t4005-1決定7のkpiの群の比較は既にある。
後者の主・副の層はADR-t4118-1とその後継の改訂を辿って読む。
また、ADR-t1728-1とADR-t3948-1のevalは固定した入力の採点と採用方針を持つ。
これらの個別の決定を、この実験基盤の一般方針に読み替えて取り消すことはしない。

## Decision

1. **DAGQの受け持ち。**
   実験条件の設定・割当・実行、事実・計測値・成果物の収集・永続化・提供と、算術の集計までを持つ。
   起動しなかったこと、失敗、欠測、意図した割当と実行のずれも事実として扱い、成功した実行だけを残さない。
   集計は入力・範囲・分母・欠測を説明でき、別の分析者が同じ材料を使える形にする。

2. **評価方針の受け持ち。**
   指標のどれを重視するか、評価のスコア、指標の重み付け、順位、modelの選定は外の分析者と道具が持つ。
   DAGQに固定の総合評価のスコアを入れず、群の割当の重みを評価の重みに流用しない。
   集計の提供を、実験の勝敗や設定の自動採用につなげない。
   共通契約が扱う収集の終了と決着の区別もこの境界の前提であり、ここで決め直さない。

3. **既存の集計とevalとの境界。**
   ADR-t3957-1決定5とADR-t4005-1決定7のkpiの群の比較は、この境界の中の算術集計と位置づける。
   群の件数、率、時間、切り替えの層を出すことは優劣の判定ではない。
   既存の試しが持つ守る指標や主・副の方針はその試し固有の決定として保ち、全実験に強制しない。
   固定入力のevalの合否・採用方針も既存の契約のまま保ち、新しい割当実験の総合評価の規則にはしない。
   通常運用の観測、制御したBenchmark、将来のReplayは、比較条件の違う材料として区別する。

## Alternatives

- **runtimeに総合スコアと順位を持たせる。** 評価の重みを変えるだけで基盤の変更が要り、将来の再分析を狭めるため採らない。
- **算術集計まで全て外に任せる。** 欠測や工程の範囲の解釈が読み手ごとに割れるため、既存の共通の読み取りと集計は再利用する。
- **既存evalの採用基準を全実験の既定にする。** 固定入力の判定の正しさと、計画・実装・手直しを含む運用の効果は異なるので採らない。
- **境界の統一のため既存の試しとevalを直ちに変更する。** 個別の受理済み決定の変更を伴うため、この追加契約では行わない。

## Consequences

測定と評価を独立に変えられる一方、最終的な採用には外の分析と人の判断が要る。
DAGQは算術が正しいことと材料の意味を説明する責任を持ち、観測した相関を因果や順位として返さない。
既存の計測の正本・ビュー・材料の区分と共通の読み取りを再利用し、実験用の第二の集計系を作らない。
