# ADR-t5121-3: 実験の書き出しを版付きにし通常観測とBenchmarkを区別する

## Context

外の分析者は実験条件、割当の履歴、失敗を含む実行結果、測定値、成果物の由来を結合する必要がある。
人向けの表示のJSONや保存先の内部表現に依存すると、CLIや保存先の変更が分析を壊す。
通常のWeighted Routingと固定した入力の比較では比較可能性が異なり、同じ形式でも区別を失ってはならない。

ADR-t5120-1はDAGQの責務を観測と算術集計までとする。
ADR-t1728-1とADR-t3948-1のevalは固定したsnapshotと独自の採点・採用方針を持ち、その決定は保つ。

## Decision

1. **内部の記録と独立した版付きの書き出し。**
   機械可読なJSONLを基本にし、実験の条件、割当の履歴、実行の結果、測定定義と値、成果物の参照を結合できる契約で出す。
   書き出し全体と各記録が解釈するスキーマの版を特定でき、入力の到達点と選択範囲も固定する。
   共通契約と役割割当契約の正本への参照・必要な写しを使い、exportから割当の正本へ逆流させない。
   本文は保持・マスキング・認可を通したものだけ参照でき、失われたものと非開示を説明する。
   中断や部分取得を完了した出力と誤認させず、同じ条件でも入力の到達点が違えば区別する。

2. **互換と版上げの方針。**
   意味・必須性・型・識別・単位・欠損の解釈を変える変更は破壊的なスキーマの版上げとする。
   既存の意味を保つ任意情報の追加は互換な版上げとし、読み手は未知の任意情報を保持または無視できる。
   未対応の破壊的な版を推測して読まず、明示して拒む。
   同じ版の意味を後から変えず、対応する旧版の出力は明示した変換で提供する。
   測定定義の版とスキーマの版は別に追跡し、古い観測に無い値を変換で作らない。

3. **算術と評価を分ける。**
   値と件数・率・時間等の算術集計は、入力・分母・欠測・推計を説明して提供する。
   DAGQはこの書き出しに順位・評価指標の重み・総合スコア・勝者・自動採用の判断を付けない。
   割当の確率の重みと外部の評価の重みを混同しない。
   既存の個別のkpiの主・副・切り替え・環境の層はその定義を保って提供でき、全実験の優劣へ一般化しない。

4. **通常観測と制御したBenchmarkを明示する。**
   通常運用の観測と、同じ入力と初期commitから独立して流す制御したBenchmarkを記録の上で区別する。
   Benchmarkでは固定した入力と初期条件の同一性、条件の逸脱、反復の対応を追跡する。
   証明する材料が欠けたものを通常観測からBenchmarkへ格上げせず、不明な条件として残す。
   同じ形式で出せても両者を暗黙に合算せず、時間帯・host・依存による干渉の情報を保つ。
   制御した比較の出力は本番の着地の権限を与えず、通常観測の相関を因果の証明と呼ばない。

5. **Replayの拡張点とevalとの共通化。**
   将来、過去に固定したsnapshotの同じ成果物を別のreviewerへ渡す比較を、元の成果物と独立した判定の由来で結べる境界を置く。
   生成・review・修正を含むEnd-to-Endの結果と、同一成果物への独立reviewを区別する。
   この決定はReplayの実行器を作らず、通常の割当から自動でReplayも起動しない。
   evalとは固定入力の取得・同一性の検査・隔離・本番と共通の起動・実行の観測の部品を共有できる。
   消えた資料を現在の状態から推定しないことと、期待・元の判定を測る側に漏らさない境界を保つ。
   eval固有のケース・split・費用上限・依頼の認可・合否と採用を実験の一般契約へ持ち込まない。

## Alternatives

- **人向けのJSONをそのまま外部契約にする。** 表示の省略と内部変更から分析を独立に保てない。
- **スキーマの版を測定の版に兼用する。** 形式が同じで測定方法だけ変わる場合を区別できない。
- **同じ群なら通常観測とBenchmarkをまとめる。** 入力と初期条件の異なる比較を混ぜてしまう。
- **evalの採点と採用を全実験の既定にする。** 既存の限定された判断を一般の価値判断へ広げるため採らない。
- **固定snapshotの記録と同時にReplayも作る。** 独立reviewの実行と安全の契約を未決のまま広げるため採らない。

## Consequences

外部の分析は保存先やCLI表示から独立し、条件と欠測を含めて再分析できる。
互換adapterと出力の完了の検査が必要になり、本文の保持切れは形式の互換だけでは救えない。
既存のADRをamendsせず、共通の実験の終了・決着と役割の固定も変更しない。
