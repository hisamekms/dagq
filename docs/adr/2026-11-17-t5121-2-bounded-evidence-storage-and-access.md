# ADR-t5121-2: Evidence本文を有限保持し秘密とアクセスを制御する

## Context

Evidenceの会話・prompt・差分・検証の出力は大きく、秘密や個人情報を含みうる。
保存量を無制限にすると、比較実験が通常運用の容量と費用を圧迫する。
既存の保持の設定、終了したrunの記録を写す計画、監査、securityの境界を別々の保存権限として広げない必要がある。

ADR-t1662-2の材料の区分は保つ。
監査は誰が何の権限で何をしたかの独立した追記の記録であり、実験用の生ログ置き場ではない。
securityのdefault denyと、hostの同一UIDに対する助言的な保証の限界を前提にする。

## Decision

1. **保存先の種類と責務を分ける。**
   既存の構造化した正本には由来と本文の利用可否を記録し、大きな本文は管理されたartifactの材料として保存する。
   本文の初期の保存先はローカルの管理領域とし、後に外部のobject保存先へ替えられるadapterの境界を置く。
   任意の場所を読ませる参照、公開リンク、資格情報入りの参照を返さない。
   終了したrunの記録の写しは取得元の候補であり、写しただけで安全なEvidenceになったとは扱わない。

2. **保持と大きさを有限の設定で管理する。**
   本文の保持期間と単体・対象別・保存先全体の大きさの上限を設定で持ち、無期限と無制限を許さない。
   期限か量のどちらかの限界に達した本文は保存を抑制または削除し、欠損の理由を残す。
   実行中の制御・復旧に必要な元の記録を、実験用の容量管理で消さない。
   既存の保持の設定と役割を分け、既存のstep・資源・台帳・eventの保持や旧方式の凍結を変更しない。
   本文の削除後も既存の記録の寿命の範囲で由来と削除理由を辿れるようにし、全情報の永久保存は約束しない。
   書き出し用の写しと終了したrunの写しも、同じ内容の別名による保持延長や容量制限の迂回に使わない。

3. **秘密の最小化とマスキング。**
   資格情報を収集対象から除外し、秘密・secret・個人情報を制御側の取り込み境界で除去またはマスクする。
   許可した種類と内容だけを保存し、除去した原文は再分析のためにも別の恒久領域へ退避しない。
   処理できない種類やマスキングに失敗した本文は公開せず、理由付きの欠損にする。
   設定とpromptの版も秘密を含まない表現で追跡し、秘密そのものの単純なhashを秘匿の代わりに使わない。
   マスキングしたことと規則の版を記録し、完全な秘密検出ができるとの保証をしない。
   書き出しにも同じ境界を適用し、古い規則の保存物を無条件に公開しない。

4. **capabilityで読む・出す・管理する権限を守る。**
   本文の読み取り、機械可読な書き出し、保持の管理をauthorizationのcapabilityと対象の規則で認可する。
   通常の状態の読み取りの許可だけでEvidence全体を取得できるようにしない。
   agentの出力はデータであり、保存先や外部の宛先を指定して権限を広げられない。
   保存先の隔離と資格情報は制御側が管理し、hostの保証と隔離された実行の保証を混同しない。
   非開示も欠損として説明するが、権限の無い対象の存在や秘密の由来を漏らさない。

5. **監査と保存費用の境界。**
   監査の独立性・追記・保持・認可を保ち、本文の削除を監査の削除へ波及させない。
   Evidenceの管理と書き出しの権限行使は既存の監査の方針で扱い、本文とsecretは監査へ複製しない。
   保存量と取得・転送を費用の対象とし、providerの推論費用と分けて観測する。
   単価が無い保存費用は不明とし、容量からの換算は推計として定義と版を持たせる。
   費用削減は原文の無期限保持や監査の弱体化の理由にしない。

## Alternatives

- **全ログをDBか監査へ詰める。** 大きさと秘密の境界を失い、監査の目的を変えてしまう。
- **容量不足のとき実行中の元ログを消す。** 実験のために通常の復旧を壊すので採らない。
- **既存の読み取り権限をそのまま全本文へ広げる。** 大量取得と機密の範囲が違うため採らない。
- **hashだけで秘密を隠す。** 低いエントロピーの値を推測でき、存在自体も漏れうる。

## Consequences

再分析の材料は有限になり、失われた本文を欠測として扱う負担がある。
一方、通常の運用・監査の保存契約を変えずに、実験用の保存量と公開範囲を制御できる。
具体の保持・容量・権限の候補は実装前の契約で管理し、実装で定義へ移す。
